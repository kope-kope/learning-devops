# DevOps Learning Log — 2026-6-6

## Q1: How to copy and paste in Vim

### First — Vim has two modes that matter here:

**Normal mode** — where you navigate and run commands (press `Esc` to get here)
**Insert mode** — where you type text (press `i` to get here)

All copy/paste commands work in **Normal mode**. If you're typing text, hit `Esc` first.

### Vim calls it "yank" (copy) and "put" (paste):

| Action | Command | What it does |
|--------|---------|-------------|
| Copy a line | `yy` | Yanks (copies) the entire current line |
| Copy 3 lines | `3yy` | Yanks 3 lines starting from cursor |
| Copy a word | `yw` | Yanks from cursor to end of word |
| Copy to end of line | `y$` | Yanks from cursor to end of line |
| Paste below | `p` | Puts (pastes) below the current line |
| Paste above | `P` | Puts (pastes) above the current line |
| Cut a line | `dd` | Deletes the line (and copies it — delete IS cut in Vim) |
| Cut 3 lines | `3dd` | Deletes 3 lines (and copies them) |
| Cut a word | `dw` | Deletes a word (and copies it) |

### The most common workflow:

**Copy a line and paste it somewhere else:**
1. Go to the line you want to copy
2. Press `yy` (yank the line)
3. Move to where you want to paste
4. Press `p` (paste below) or `P` (paste above)

**Move a line (cut and paste):**
1. Go to the line
2. Press `dd` (this cuts it)
3. Move to the destination
4. Press `p`

### Visual mode — select exactly what you want:

If `yy` (whole line) is too broad:
1. Press `v` to enter **Visual mode** (character selection)
2. Use arrow keys or `h/j/k/l` to highlight the text you want
3. Press `y` to yank the selection
4. Move to destination, press `p`

For selecting whole lines visually: `V` (capital V) enters **Visual Line mode**.
For selecting a block/column: `Ctrl+v` enters **Visual Block mode**.

### Copy/paste from OUTSIDE Vim (your system clipboard):

This is where people get stuck. Vim has its own internal clipboard (called "registers"), separate from your Mac's clipboard. To paste something you copied from Chrome into Vim:

**On Mac:**
- In Insert mode: `Cmd+V` works in most terminal apps
- In Normal mode: `"+p` pastes from system clipboard
- To copy TO system clipboard: select in Visual mode, then `"+y`

**If `"+y` doesn't work**, your Vim might not have clipboard support. Check with:
```bash
vim --version | grep clipboard
# You want +clipboard, not -clipboard
```

### Quick reference cheat sheet:

```
yy    → copy line
dd    → cut line
p     → paste below
P     → paste above
u     → undo (if you mess up)
v     → visual select
:     → command mode
:wq   → save and quit
:q!   → quit without saving
```
